# Sticky Notes

Desktop sticky-notes board built with React and TypeScript (Vite).

## Run

```bash
npm install
npm run dev
```

Open the URL printed by Vite (usually http://localhost:5173).

## Build

```bash
npm run build
npm run preview
```

## Features

- Create a note by clicking empty board space
- Move by dragging the note
- Resize from the bottom-right corner
- Delete by dropping onto the trash zone
- Edit text, bring-to-front on interaction, color rotation, localStorage persistence
